# 설정창과 즉시 적용

> 최신 후속: [브랜드·단축키와 설명 제거](KEYBOARD_BRAND.md). 설정창 상·하단과 X 툴팁의 저장 설명을 제거하고 즉시 저장 동작은 유지했다.

> 2026-10-13 후속: 고정 크기 독립 설정창·종료 안내와 최신 빌드/검증은 [요청 8~11 후속 구현 결과](FOLLOWUP.md)를 따른다. 아래 검증 해시는 즉시 저장 방식으로 처음 변경한 당시 기록이다.

사용자의 후속 요청에 따라 설정창의 색상·글꼴·간격과 저장 방식을 변경했다. `feature.md`의 미검증 항목 전체가 완료됐다는 뜻은 아니다.

- 본창과 같은 다크/라이트 배경, 터미널 글꼴과 한글 폴백, 민트 강조색을 사용한다. 설정창의 여백·컨트롤 간격을 늘리고 섹션 제목과 설명, 이름이 있는 탭으로 구분한다. 후속 변경으로 앱 크기와 무관한 560×720 DIP 독립 창을 사용하며 본문을 스크롤한다.
- 저장·취소 버튼을 제거했다. 유효한 변경은 즉시 적용·저장하고, X는 설정창만 닫는다. 다시 열거나 앱을 재시작해도 적용한 설정이 유지된다.
- 잘못 입력한 단축키·파일 경로 등은 오류를 표시하고 마지막으로 적용한 값을 유지한다. 입력 중인 잘못된 항목 때문에 다른 설정 변경을 막지 않는다. 적용 실패 안내는 해당 입력을 고치거나 설정창을 닫을 때까지 유지한다.
- 셸·시작 폴더·스크롤백은 새 탭부터 적용한다. 프롬프트 변경은 열린 세션의 다음 프롬프트부터 적용한다. 테마·글꼴·투명도·알림 설정은 현재 앱에도 적용한다. 설정 변경으로 셸을 재시작하지 않는다.
- 알림 탭은 팝업 표시 조건, 클릭하면 해당 탭으로 돌아가는 동작, 팝업을 꺼도 알림 목록을 유지하는 동작을 설명한다. 소리 선택은 팝업을 끄면 비활성화하되 선택한 값은 유지한다.
- 모호한 에이전트 연결 대신 **CLI 응답 알림 등록**으로 표시한다. Codex는 응답 종료, Claude Code는 응답 종료·응답 오류·승인/입력 필요 이벤트를 받는다고 설명한다. 등록·해제 결과를 설정창 하단에 표시한다. 등록 후 새 MiniTerm 탭에서 CLI를 시작해야 한다.
- CLI 알림 등록·해제와 Windows 앱 알림 등록은 명시적인 버튼 동작이다. Windows 사용자 CLI 설정에만 적용하며, 기존 콜백/훅을 보존한다. WSL 안의 CLI 설정 등록은 지원하지 않는다.

검증 명령:

```powershell
./scripts/cargo.ps1 -CargoArguments @('test','--locked','--lib')
./scripts/build.ps1
./scripts/verify-settings.ps1
./scripts/verify-ux.ps1
```

`verify-settings.ps1`은 별도 데이터·IPC·CLI 설정으로 체크박스/테마의 즉시 저장, X·다시 열기·재시작, 잘못된 입력과 다른 컨트롤, 열린 세션 프롬프트 상태·동일 세션 ID, 알림 등록/해제와 원래 콜백 보존, 작은 창 배치를 검사한다. 실제 모델 호출·Windows 알림 등록 변경·실제 팝업 클릭 검사는 포함하지 않는다. 기존 사용자 앱을 종료하지 않는다.

- `scripts/test.ps1`: 일반 자동검사 **64개 통과**(단위 63개·fixture 1개). 무시된 환경 검사는 통과로 세지 않는다.
- 설정창 GUI: `artifacts/settings-a42697f1-5b05-4009-87a7-41d353f7817b/verification.json`. 즉시 저장·X·다시 열기·재시작·투명도와 네이티브 alpha·알림 등록/해제·잘못된 단축키와 별도 설정 변경·열린 프롬프트 상태/세션 유지·320px 네 탭 배치 모두 통과했다.
- 기본 UX: `artifacts/ux-e27dff04-a61b-430c-9399-9dc731ddc9b8/verification.json`. 실제 VT 표본·미니 입력 하단 배치·다크/라이트·확장 폭/하단 유지·본문 위치별 더블 클릭·이동/크기 저장·시험 셸 종료 통과. 이 실행에는 요약 표본을 포함하지 않았다.
