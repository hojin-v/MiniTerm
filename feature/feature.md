번호는 원래 요청 번호를 유지한다. 구현·검증 근거는 [초기 구현](IMPLEMENTATION.md), [설정창 개선](SETTINGS.md), [8~11번 후속 결과](FOLLOWUP.md), [브랜드·단축키 후속](KEYBOARD_BRAND.md), [Codex 스크롤 수정](SCROLL.md)을 따른다. 채팅의 후속 요청에는 12·13·14번을 붙였다. 실제 동작 확인이 남은 항목은 완료와 구분한다.

2026-10-14 작업을 재개했다. 배터리 과다 사용을 [별도 진단](../performance/BATTERY_DIAGNOSIS_2026-10-13.md)한 뒤 기능 검증을 이어갔다. 최신 변경·통과/실패 근거·재개 순서는 [Codex 입력·재개·Bash 연결 인계](CODEX_RECOVERY_HANDOFF.md)에 정리했다.

2026-10-15 사용자 요청에 따라 성능 진단은 별도 성능 세션으로 넘기고 기능 구현을 재개했다. 공유 Codex의 탭별 알림을 추가했다. [공유 알림 구현·검증](SHARED_NOTIFICATIONS.md)을 따른다.

2026-10-16 공유 알림의 임시 대화 간섭·완료 배지 변경과 원격 TUI의 작업 폴더를 수정했다. 일반 88개와 별도 기능 release의 실제 Codex 통합 검사(탭 이동 재개·Bash·R·콜백 보존)를 통과했다. 실제 입력과 남은 호환성 문제는 미완료 항목에 유지한다.

2026-10-18 설치본의 새 다섯 증상과 설정창 동시 표시의 글자 깨짐을 처리 중이다. 번호 3은 회귀 요청으로 미완료로 옮기고 새 요청에는 16~20을 붙였다. 구현·Windows/WSL 중간 GUI 통과 및 최종 release의 Defender 격리를 [후속 기록](FOOTER_LIFECYCLE_2026-10-18.md)에 구분했다. 최종 파일을 정상 배포·검증 완료로 표시하지 않는다.

- **5.** 상태줄에 MiniTerm은 제거하고 앱 아이콘만 남도록(앱을 잘 표현하는 브랜드 이미지(svg등 고화질 권장) 필요-응용프로그램 설치,실행 파일에도 이미지 필요)
  - 후속 디자인 요청에 따라 겹친 장식을 제거하고 M의 윤곽과 터미널 끝선을 하나의 민트색 경로로 통합했다. 같은 SVG·ICO를 상단·설정창·트레이·창·EXE·설치/제거 아이콘에 적용했다.
- **6.** codex에서 마우스 스크롤이 이전 입력 내용 전환으로 동작함. 최근 실행 파일에서는 스크롤 자체가 동작하지 않음
  - 출력 기록·휠 갱신·축소 입력 화면을 수정하고 기본 배터리를 `inline`으로 변경했다. 공유 서버를 프런트엔드 전에 준비하는 경로에서 첫 입력의 RGB 오염 없음·확장/축소 위아래 스크롤·초안·세션 보존을 실제 release GUI로 확인했다. Win32 휠 → winit → egui 검사이며 물리 휠 장치/사용자 계정 검증과 구분한다. [최신 근거](CODEX_RECOVERY_HANDOFF.md)를 따른다.
- **8.** 마우스 온 했을 때 내용이 짤린 것도 아니고, 아이콘 설명도 아닌 같은 내용을 툴팁으로 띄우고 있는 경우가 있음
  - 다 보이는 요약 문장은 반복 툴팁을 제거했다. 잘린 문장만 안내 하나를 띄우며 배터리는 실제 VT 칸으로 잘림을 판단한다. 실제 호버에서 각각 0개/1개를 검증했다.
- **9.** 에이전트의 전체 작업 진행도(%)와 현재 작업 정보가 요약에 제대로 표시되고 있는지 확인하고, 표시하기 위한 구현 방법도 명확하게 기록
  - 프로젝트 스킬 어댑터 → helper → IPC → 선택된 탭 요약의 실제 보고 경로로 33%·66%·100%, 한글 현재 작업·중단·거짓 완료 거부·탭 분리를 검증했다. [표시 방법과 구현](PROGRESS.md)에 사용 예시·갱신 규칙·적용 범위를 기록했다. 실제 모델이 스킬을 자동 선택하고 계속 보고하는 것을 보장하는 기능은 아니다.
- **10.** 설정창의 크기를 앱 크기에 따라 변경하지 말고, 고정 크기로 깔끔하게
  - 560×720 DIP의 독립 설정창으로 변경했다. 작은 HUD·숨긴 HUD에서도 크기를 유지하고 즉시 적용·저장과 X 닫기를 검증했다. 본창과 같은 색상·글꼴·민트 강조색을 사용한다.
- **11.** 설정창의 종료버튼을 제거. 종료 시 확인 안내를 간략하게 줄이고, 버튼의 가로폭을 늘려서 안내창과 버튼의 여백이 적도록. 버튼을 아이콘 대신 닫기/모두 닫기 / 취소 이런 텍스트 안내로 변경하고, 앱과 어울리지 않는 빨간색도 사용하지 않는다.
  - 설정창에서 앱 종료 버튼을 제거했다. X는 설정창만 닫는다. 종료 안내는 한 문장, 버튼은 취소/닫기 또는 취소/모두 닫기의 넓은 텍스트 버튼이며 앱의 중립색·민트 강조색을 사용한다. 취소 시 세션 유지와 실제 탭/앱 종료를 검증했다.

- **12.** 설정창에 X로 닫아도 설정이 저장된다는 설명은 제거
  - 상단의 즉시 적용/저장 설명·하단의 X 저장 설명·닫기 툴팁의 같은 설명을 제거했다. 오류/등록 결과만 필요할 때 표시하고 즉시 저장 동작을 유지한다. 새 배치의 설정 GUI 회귀를 통과했다.

- **15.** 설정창의 둥근 모서리 밖에 배경색이 보이고 한글·영문의 높이가 맞지 않음
  - 내부 배경의 별도 둥근 테두리를 제거하고 본창과 같은 Windows의 작은 모서리를 적용했다. 일반 UI는 맑은 고딕 한 글꼴로 영문·한글을 표시하고 터미널/명령용 고정폭 글꼴은 유지한다. release 캡처에서 모서리·혼합 문장을 확인했고 설정 GUI 회귀(고정 크기·즉시 저장·재시작·Bash 연결 적용/해제)를 통과했다. 근거는 현재 인계를 따른다.

# 작업했으나 미완료

- **3.** exit, 탭 종료를 해도 logout이라고 하고 안 사라짐 — 마지막 탭에서 재보고

- **16.** Windows Codex/Claude 실행 시 AI Battery가 입력 위에 뜨거나 입력 뒤 사라짐

- **18.** 창 테두리의 크기 조절 커서가 간헐적
  - DPI 경계 폭을 7 DIP로 늘리고 hit-test에 맞는 시스템 커서를 명시했다. 중간 GUI의 8방향 네이티브 메시지 반복은 통과했다. 최종 release와 실제 포인터 확인은 남는다.

- **20.** 설정창을 열어 둔 동안 MiniTerm 본창 글자가 깨짐
  - 설치본 alpha.7에 없는 다중 viewport 글꼴 atlas 수정이 현재 소스에 포함돼 있다. 해당 수정의 이전 픽셀 통과 근거를 유지한다. 새 최종 release의 다크/라이트 동시 창 픽셀 비교는 Defender의 실행 거부로 미완료다.

위 3·16~20의 새 실행 파일은 Defender가 `Trojan:Win32/Bearfoos.A!ml`로 탐지·격리했다. 오탐을 확정하지 않으며 보호 기능을 바꾸거나 다른 실행 파일로 우회하지 않았다. [후속 기록과 다음 검사](FOOTER_LIFECYCLE_2026-10-18.md)를 따른다.

- **2.** 투명도 설정이 빠르게 설정가능 하도록(숨기기 버튼과 통합하여 단일 클릭시 숨기기, 마우스온 대기 시 위로 조절 세로바가 플로팅되어 조절, miniterm에 마우스 올린 상태로 특정키+마우스 스크롤하면 투명도 조정)

- **4.** 탭추가에 대한 단축키 필요
  - `Ctrl+Shift+T`와 최대 4개 제한, Bash로 키 전달을 막는 처리를 구현·자동검사했다. 네이티브 입력 도구에서 Ctrl 상태가 유지되지 않아 실제 키보드 조합의 GUI 확인은 완료로 표시하지 않는다.

- **7.** wsl이 동작하지 않음(파워쉘 명령어를 사용하진 않지만 기본적으로 윈도우 기본 터미널에서 되는 기능이 안 되는 문제가 있으면 대체 프로그램으로써 가치에 문제가 있으니 기본 기능에 대해 엄격한 검토가 필요(불가능한 기능이 있다면 명확히 명시해야함))
  - 사용자가 알려준 Git Bash 입력창 → `wsl` 경로에서 기본 호출은 이 환경에서 수정 전후 모두 동작했다. Linux 인수가 MSYS에서 Windows 경로로 바뀌는 실패는 재현·수정했고 WSL2 실기 3개를 통과했다. 사용자 원증상 재현과 기본 터미널 호환성 검토는 미완료이며 설치 Git의 기존 빠른 resize/입력 실패 4건도 남는다. 지원 범위·한계는 [초기 구현](IMPLEMENTATION.md)에 기록했다.

- **14.** Codex 시작 시 RGB 응답 문자열 입력, 다른 앱에서 열린 대화 경고와 R 재시도 실패/멈춤을 해결하고 Bash 명령 실행을 유지할 명확한 방법을 마련

[공유 알림 검증](SHARED_NOTIFICATIONS.md)과 [현재 인계](CODEX_RECOVERY_HANDOFF.md)를 따른다.

현재 착수하지 않은 새 요청은 없다. 3·16~20은 보안 검토 뒤 최종 검증을 이어가고, 기존 2·4·7·13·14의 남은 범위도 미완료로 유지한다.
