## 확인한 실행 경로와 남은 가설

`portable-pty 0.9.0`의 `src/win/psuedocon.rs::load_conpty`는 `conpty.dll`을 이름만으로 열어 성공하면 kernel32의 ConPTY보다 우선 사용한다. 현재 PATH에서 발견한 DLL은 `C:\Users\ghwls\AppData\Local\ai-battery\bin\conpty.dll`이며 버전 1.23.2510.08001이다. 이름만으로 DLL을 여는 기본 Windows 검색 순서에는 현재 폴더와 PATH도 포함된다. [Microsoft DLL 검색 순서](https://learn.microsoft.com/en-us/windows/win32/dlls/dynamic-link-library-search-order).

메모리를 제한한 실제 MiniTerm 검사에서 해당 DLL이 **MiniTerm 프로세스에 로드된 모듈**임을 관찰했고, 그 옆의 OpenConsole도 자식 프로세스에서 확인했다. 따라서 AI Battery의 rowpty 내부만 외부 콘솔을 쓰는 것이 아니라 MiniTerm의 바깥 Bash 콘솔도 이 DLL을 자동 선택할 수 있다. 실제 사고 PID의 이미지 경로·부모 관계는 직접 관찰하지 못했으므로 당시 PID 10556의 소속을 확정한 기록으로 읽지 않는다.

관찰한 외부 DLL SHA256:

- `conpty.dll`: `7c7430632052ff703540b68371ec43821820aa1335d8e11dfbcd9ff00e9daaed`
- `OpenConsole.exe`: `d1fe7faa62f9e955e2ac2371f95d7e5513df4d496255097158f979c94782c5fc`

사고 실행 파일은 [스크롤 변경](../feature/SCROLL.md)의 기본 `tui`/rowpty 경로를 포함한다. 조사 중 다른 기능 세션이 `src/shell.rs` 기본값을 `inline`으로 변경하는 것을 확인했다. 이 변경은 이번 조사에서 수행하지 않았고, 기존 실행 파일에 적용됐다고 가정하지 않는다. 색상 응답의 키 입력 변환·중첩 ConPTY·resize/재개 상태가 후보 경로이며, 단독 누수 원인으로 확정한 것은 없다.

MiniTerm 자체의 출력 큐는 16×16KiB, 입력은 1MiB, PTY 크기는 2..1000열 / 1..500행으로 제한돼 있다. 이 제한은 Windows 콘솔 내부의 커밋 증가까지 막는 장치가 아니다. `ProcessJob`도 현재 메모리 한도를 설정하지 않는다. 사고 직전 MiniTerm의 working set은 확보하지 못했다.

동시 Application 오류 중 Sunshine 반복 충돌과 LiveKernelEvent 193도 있었으나 커널 보고가 가리킨 덤프 날짜에는 이전 사고가 포함돼 있다. 같은 시간에 보고된 것만으로 이번 OOM의 원인 또는 결과로 단정하지 않는다.

## 이번 소스 변경

- `src/console_host.rs`: `SetDefaultDllDirectories(LOAD_LIBRARY_SEARCH_DEFAULT_DIRS)`를 한 번 적용한다. MiniTerm의 DLL 검색에서 암묵적인 현재 폴더/PATH 선택을 제외하고 앱 디렉터리·System32·명시적으로 추가한 DLL 경로를 유지한다. 셸의 명령 PATH나 사용자 설정 파일은 수정하지 않는다. [Microsoft API 문서](https://learn.microsoft.com/en-us/windows/win32/api/libloaderapi/nf-libloaderapi-setdefaultdlldirectories).
- `src/pty.rs`: 첫 PTY를 열기 전에 이 정책을 적용한다. `src/lib.rs`에서 모듈을 연결하고 Cargo에 LibraryLoader 기능을 명시했다.
- 단위 검사는 새 자식 프로세스의 PATH에 시험 DLL을 놓고, 정책 전에는 로드되지만 이후에는 차단되는지와 명시적 DLL 경로의 보존을 확인한다. 테스트 DLL은 Windows `version.dll`의 시험 소유 사본이며 AI Battery 설치에 의존하지 않는다.

이는 외부 DLL 자동 선택을 차단하는 변경이다. 콘솔 메모리 상한·자원 감시·입출력 루프 차단을 구현하거나 재발 방지를 입증한 것으로 표시하지 않는다. 앱 옆에 의도적으로 배치한 ConPTY는 계속 선택될 수 있다.

## 기존 실행 파일의 임시 우회

MiniTerm을 새로 실행할 때 다음 스크립트를 사용할 수 있다.

```powershell
./scripts/start-system-console.ps1
```

새 MiniTerm 프로세스의 PATH에서 관찰된 `ai-battery/bin`만 제외하고 `AI_BATTERY_DISABLE_WINDOWS_CODEX_RUNNER=1`을 전달한다. 현재 EXE에서 Windows 시스템 ConPTY와 Codex 직접 실행을 사용하는 임시 경로다. **AI Battery의 터미널 하단 runner는 우회된다.** 사용자 설정·인증·시작 파일·전역 환경은 변경하지 않는다. 이미 같은 실행 파일이 열려 있으면 환경이 적용되지 않으므로 안내와 함께 중단하며 기존 사용자 앱을 종료하지 않는다. `-CheckOnly`는 실행 없이 대상과 변경 범위를 출력한다.

이 우회에서도 OOM 재발 방지까지 검증한 것은 아니다. 소스 변경은 기존 `artifacts/miniterm.exe`에 아직 포함되지 않았다.
