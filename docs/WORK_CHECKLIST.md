고정 요약/보고와 구버전 어댑터 기록은 이전 fixture를 유지한다. 이전 e625 빌드의 10초 유휴 최대 working set은 205,062,144bytes로 목표를 초과했으며 이번 UI 수정에서 메모리 검사를 반복하지 않았다. 입력 누락·메모리·실제 사용자 검증의 P0 항목은 남는다.

격리 MSYS v3 DLL(`bd667421…`)의 최종 입력·신호·연동 기록은 [런타임 검증](patches/MSYS_RUNTIME_VALIDATION.md)에 있다. 같은 staging 앱과 명시적 Bash 경로를 쓴 `artifacts/ux-5f655c3b-8f81-4bd9-9f8d-eeb4c6d8248e`에서도 읽기 쉬운 활동·상태·태스크와 툴팁 하나를 확인했다. 기본 제품/설치 Git의 기존 실패 기록은 후보의 통과로 대체하지 않는다. 런타임 제품 적용과 다른 버전·실기·부하 검증이 남으며 현재 사용자 PID 5852는 유지했다.

사용자가 이전 버전 종료·최신본 실행을 요청해 PID 10756·29644를 종료했다. 실행 파일/설정을 백업하고 같은 설치 경로의 최신본 PID 5852 하나를 실행했다. 새 Bash, 창 표시와 `progress-v1`을 확인했고 실행 시 설정 SHA256은 그대로였다. 전역 Codex 설정은 변경하지 않았다. `artifacts/manual-test/latest-running.json`에 현재 실행 정보를 기록했으며 이전 Codex/셸 작업은 새 세션에서 자동 복원하지 않는다.
