# MiniTerm v0.1.0-alpha.7

Windows 11 x64용 Hnode 테스터 알파다. Codex의 공유 대화·Bash 실행·탭별 상태 연결과 터미널 자원 보호를 보완했다.

## 변경

- Windows Codex의 기본 실행 도구를 Git Bash로 등록하고 공유 서버를 먼저 준비한다. 같은 대화의 이력·호출 폴더·기존 옵션과 콜백을 보존하며, 탭 이동 재개와 writer 충돌 뒤 R 복구를 지원한다. 등록은 MiniTerm 밖의 Windows Codex에도 적용된다.
- 공유 Codex의 성공한 대화 연결을 기준으로 탭별 완료·승인/입력 요청·오류를 구분한다. 알림 IPC를 원본 전송에서 분리하고 느린 상태 전달은 최신 값으로 병합한다.
- TUI 스크롤·확장/축소의 화면 보존, 설정창과 글꼴·한글·ANSI 표시, 키보드 단축키 및 브랜드 아이콘을 개선했다.
- 새 바깥 콘솔 호스트에 256MiB 커밋 상한을 적용한다. history의 고정 셀 공간은 32MiB 기준으로 제한하고 가로 확대 전에 줄인다. 한 셀의 결합 문자는 suffix codepoint 64개까지 저장한다.
- 가득 찬 FIFO 밖에서 종료를 처리하고 자체 동기 파이프 IO를 취소한다. VT 잠금을 푼 뒤 자동 응답을 보내며, 응답 폭주 시 해당 세션을 중단한다. 정상 셸 종료의 마지막 출력은 배출한다.
- 시스템 글꼴을 읽기 전용 파일 매핑으로 공유하고 큰 executor 프레임은 원본 스트리밍으로 전달한다. 서버 시작 오류는 제한된 크기로 수집한다.

## 검증 범위

로컬 사전검증은 일반 검사 96개, 실제 ConPTY의 콘솔 한도·종료·마지막 출력, 총 18만 행 출력, 1/4세션 GUI 및 설치 Codex 0.163.0의 공유 대화·Bash·알림·재개·R 복구를 포함한다. 고정 localhost 제공자와 자체 설정만 사용했으며 실제 계정/모델 호출은 없다.

동일 화면의 30초 유휴 로컬 사본에서 최대 앱 working set은 1세션 150.1MB, 4세션 152.9MB였다. 글꼴 변경 전 1세션 206.5MB와 구분한다. 이 수치는 해당 장치·로컬 실행 파일의 결과이며 CI 공개 실행 파일·다른 장치의 메모리나 전력 소모를 보장하지 않는다. [상세 근거](https://github.com/hojin-v/MiniTerm/blob/v0.1.0-alpha.7/performance/STABILITY_2026-10-16.md)를 참고한다.

공개 파일은 태그 CI의 포맷·Clippy·일반 검사·격리 IPC·기본 Git 호환성·빌드·패키징·설치/제거 검증을 거쳐 게시한다. 공개 실행 파일의 커밋과 해시는 `BUILD_INFO.json`, 해당 러너의 Git 결과는 `COMPATIBILITY.json`, 다운로드 해시는 `SHA256SUMS`에서 확인한다.

## 설치와 남은 제한

`MiniTerm-0.1.0-alpha.7-windows-x64-setup.exe` 또는 `MiniTerm-0.1.0-alpha.7-windows-x64.zip`을 받는다. 기존 작업을 마치고 MiniTerm을 종료한 뒤 업데이트한다. 설치본과 ZIP은 같은 사용자 설정을 사용한다. Git for Windows와 Microsoft Visual C++ v14 x64 런타임이 별도로 필요하다.

기본 Git/MSYS의 resize 직후 입력 누락 4건은 남는다. 수정 MSYS DLL은 번들하지 않는다. 10월 13일 메모리 고갈 사고의 정확한 트리거·할당 스택은 미확정이며 이번 보호 조치가 모든 OOM을 해결했다는 뜻은 아니다. 실제 IME·알림 클릭·장시간 계정 대화·혼합 DPI·다른 GPU/Windows·입력→픽셀 지연과 코드 서명 검증도 남는다.

WinGet PR은 alpha.6 기준으로 별도 검토 중이며 이번 GitHub 배포만으로 카탈로그 버전이 갱신되지는 않는다.
