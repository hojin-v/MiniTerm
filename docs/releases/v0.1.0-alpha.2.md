# MiniTerm v0.1.0-alpha.2

Windows 11 x64용 테스터 알파다.

- 미니 입력 화면이 두 줄까지만 표시하던 제한을 제거했다. 창의 사용 가능한 행을 활용하고 입력 커서를 하단에 맞춘다. 선택·마우스 좌표와 IME 위치도 같은 표시 영역을 사용한다.
- 글꼴 atlas 폭을 조정해 한글·기호·테마 전환 뒤 메모리 초과를 줄였다. 앞선 수정판의 30초 측정은 1세션 184.6MB, 4세션 185.3MB였으며 GPU 전체·출력 부하·입력→pixel 측정을 대체하지 않는다.
- 설치 프로그램의 게시자는 Hnode다. 공식 WinGet 등록 ID는 `Hnode.MiniTerm`, 이름·별칭 설치 안내는 `winget install miniterm`이다. Microsoft 검증·병합·카탈로그 반영 전에는 이 설치 명령이 제공되지 않는다.

Git Bash 크기 변경 직후 첫 글자 누락은 남아 있으며 실험용 MSYS DLL을 포함하지 않는다. 코드 서명·다른 장치의 IME/DPI·실제 계정 응답·Windows 알림 클릭·WSL·출력 부하 검증은 완료되지 않았다. 기존 alpha.1의 설치 파일과 태그는 변경하지 않는다. 설치·업데이트 전에는 작업을 마치고 MiniTerm을 종료한다.
