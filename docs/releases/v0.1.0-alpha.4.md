# MiniTerm v0.1.0-alpha.4

Windows 11 x64용 Hnode 테스터 알파다. 개발 중이던 앱 변경을 정리하고 배포 검사를 보완했다.

- 앱 옆 `runtime/git` 구성이 있으면 Bash/MSYS DLL의 SHA256과 필수 파일을 확인해 선택한다. 손상된 구성은 오류를 표시하며 설정에서 지정한 Bash 경로는 우선한다.
- **이번 설치본과 ZIP에는 수정 Bash/MSYS 런타임을 포함하지 않는다.** Git for Windows와 Microsoft Visual C++ v14 x64 런타임을 별도로 설치해야 한다. 기본 Git의 리사이즈 직후 입력 누락은 여전히 알려진 문제다.
- 상태·한글·잡 제어 검사를 리사이즈 전에 완료하도록 정리했다. 리사이즈 직후 입력은 기존 네 전용 회귀 검사에서 계속 검사하며 허용 실패 목록을 늘리지 않았다. 실제 태그 CI 결과는 `COMPATIBILITY.json`에 제공한다.
- 로컬 SSE 시험 서버에서 대기 연결이 실제 요청을 막는 문제를 수정하고 회귀 검사를 추가했다. 로컬 로직 56개·회귀 1개와 fmt·Clippy가 통과했다.

설치 파일은 `MiniTerm-0.1.0-alpha.4-windows-x64-setup.exe`, 압축형은 `MiniTerm-0.1.0-alpha.4-windows-x64.zip`이다. `SHA256SUMS`로 다운로드를 확인한다. 업데이트 전 진행 중인 작업을 마치고 MiniTerm을 종료한다. 소스 커밋과 실행 파일 해시는 `BUILD_INFO.json`을 기준으로 한다.

WinGet 제출은 alpha.3이며 Microsoft 검토와 카탈로그 반영은 별도다. alpha.4는 이 Release에서 직접 받는다. 서명, 실제 IME/혼합 DPI·계정/모델·Windows 알림 클릭·WSL·출력 부하 검증은 남아 있다. alpha.3의 공개 빌드는 4세션 유휴 측정에서 200MB 목표를 초과했으며 alpha.4의 성능 개선을 주장하지 않는다.
