# MiniTerm v0.1.0-alpha.8

이번 버전은 입력·Codex 연결·설정창 표시와 설치 경험을 보완한다.

- 창 크기 변경 직후 명령의 첫 글자가 사라지는 MSYS 경쟁 상태를 수정했다. 최신 PortableGit 2.56.0(2) 기반의 전용 Bash를 포함하며 사용자 Git 설치와 전역 PATH는 변경하지 않는다.
- Codex 세션 선택창과 새 대화가 보조 연결을 열 때 기존 연결 때문에 대기하던 문제를 수정했다. 탭 종료 시 해당 중계만 정리하고 공유 서버와 대화 이력은 유지한다.
- Codex 대기 중 Windows 연결 중계가 비차단 소켓을 반복 조회해 한 CPU 코어를 계속 사용하던 문제를 수정했다. 소켓 대기를 사용하면서 연결 종료·취소는 유지한다.
- 설정창을 열 때 공유 글꼴 atlas 설정이 달라져 본창 글자가 깨지는 문제와, 확장·축소 뒤 움직이지 않은 커서에서 스크롤이 무시되는 문제를 수정했다.
- 설치 과정에서 시작 메뉴 표시·바탕화면 바로가기·Windows 로그인 시 실행을 선택할 수 있다. 업데이트 때 선택을 기억하고, 완료 화면에 설치 위치와 바로 실행 옵션을 표시한다.
- 자동 실행은 기본 해제다. 설치 선택과 앱 설정을 함께 저장하며, 다른 설정 항목과 사용자 파일은 보존한다. 실행 중인 앱은 강제 종료하지 않고 설치 화면에서 정상 종료 후 재시도할 수 있다.
- 배포는 소스 빌드, 호환성 전체 통과, 실제 설치 옵션·업데이트·제거 검사 후에만 게시한다. SHA256 목록과 수정 런타임 전체 소스·빌드 기록을 제공한다.

설치 파일: `MiniTerm-0.1.0-alpha.8-windows-x64-setup.exe`. 압축형은 `MiniTerm-0.1.0-alpha.8-windows-x64.zip`을 폴더 전체로 풀어 실행한다. 단독 EXE에는 Bash가 포함되지 않으므로 설치 파일이나 ZIP을 권장한다.

Windows 11 x64, DX12 그래픽 드라이버와 Microsoft Visual C++ v14 x64 런타임이 필요하다. Codex·Claude Code·AI Battery의 설치와 로그인은 별도다. 설치본은 아직 코드 서명이 없으며, 이 버전은 검증 범위를 명시한 알파다. 실제 IME·혼합 DPI·다른 GPU·장기간의 외부 계정 대화는 자동 검사 범위와 구분한다.
