# MiniTerm v0.1.0-alpha.6

Windows 11 x64용 Hnode 테스터 알파다. alpha.5의 앱 변경과 배포 검증을 유지하고 WinGet 무인 제거를 수정했다.

- 설치 프로그램이 `QuietUninstallString`에 NSIS `/S` 제거 명령을 등록한다. 이전 설치본에는 이 값이 없어 WinGet의 무인 제거가 일반 제거 창을 열 수 있었다.
- 게시 전 CI에서 실제 설치·앱 로딩·무인 제거 등록·제거·설정 보존을 확인한다. WinGet 검사는 명령의 성공 메시지뿐 아니라 실제 파일과 레지스트리의 제거를 확인한다.
- 앱 옆 전용 Bash 폴더의 SHA256 검증과 명시적 사용자 경로 보존을 포함한다. **수정 Bash/MSYS DLL은 포함하지 않는다.** Git for Windows와 Microsoft Visual C++ v14 x64 런타임이 필요하다.
- 테스트 데이터를 격리해 실제 사용자 설정 경로와 설치 검사가 충돌하지 않도록 했다. 실제 기본 Git 검사 결과는 `COMPATIBILITY.json`에 제공한다.

`MiniTerm-0.1.0-alpha.6-windows-x64-setup.exe` 또는 `MiniTerm-0.1.0-alpha.6-windows-x64.zip`과 `SHA256SUMS`를 받는다. 기존 MiniTerm의 작업을 마치고 종료한 뒤 설치한다. 이전 버전 위에 설치하면 무인 제거 등록도 갱신된다.

기본 Git의 리사이즈 직후 입력 누락, 공개 빌드의 200MB 메모리 목표 미달, 서명과 실제 IME/혼합 DPI·계정/모델·알림 클릭·WSL·출력 부하 검증은 남아 있다. WinGet 공식 설치는 Microsoft PR 승인·병합·카탈로그 반영 후 가능하다. Headless WinGet 기능 검사의 보안 프롬프트 조정은 일회용 러너에만 적용·복원하며 사용자 장치의 보안 평판 통과를 의미하지 않는다.
