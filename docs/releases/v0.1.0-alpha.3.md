# MiniTerm v0.1.0-alpha.3

Windows 11 x64용 Hnode 테스터 알파다. 미니 입력의 가용 행 활용·하단 정렬과 글꼴 캐시 메모리 보완을 포함하고, 설치 안내 문서를 현재 버전으로 맞췄다. 이후 배포에서는 패키지에 포함된 안내의 설치본·ZIP 파일명이 릴리스 버전과 일치하는지 게시 전에 검사한다.

- 입력 커서는 미니 화면의 사용 가능한 영역 하단에 놓인다. 최근 출력은 두 행 제한 없이 창에 들어가는 행을 사용한다. VT 크기는 축소 시 보존하고 선택·마우스·IME 좌표도 같은 표시 영역을 사용한다.
- 같은 소스의 release 수정판은 4세션·기호·요약·계획 보고 회귀와 30초 유휴 측정에서 최대 185.8MB를 기록했다. 실제 모델 응답·GPU 전체 메모리·출력 부하·입력→pixel·다른 장치를 검증한 결과는 아니다.
- 게시자는 `Hnode`, 공식 WinGet 등록 ID는 `Hnode.MiniTerm`이다. Microsoft 승인·병합·카탈로그 반영 후 `winget install miniterm` 또는 `winget install hnode.miniterm`으로 설치한다. 카탈로그 등록 전에는 GitHub Releases 설치본을 사용한다.

기본 Git Bash 크기 변경 뒤 첫 글자 누락은 남아 있으며 수정 MSYS DLL은 포함하지 않는다. 서명·실제 IME/혼합 DPI·계정/모델·Windows 알림 클릭·WSL·부하 검증은 완료되지 않았다. 설치·업데이트 전에는 작업을 마치고 MiniTerm을 종료한다. 기존 릴리스의 설치 파일·태그는 변경하지 않는다.
