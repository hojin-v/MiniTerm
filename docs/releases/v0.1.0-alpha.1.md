# MiniTerm v0.1.0-alpha.1

Windows 11 x64용 첫 테스터 알파입니다. 안정판이 아니며 알려진 입력·성능 문제를 포함합니다.

## 제공 기능

- 지속되는 Bash 세션과 네이티브 DX12 작은 터미널
- 이동·마우스 크기 조절·더블 클릭 확장/축소, 다크/라이트·글꼴·투명도
- ANSI 스타일·한글·TUI 기호 폴백
- 읽기 쉬운 작업 요약, 명시된 태스크의 완료 비율, 중복 없는 긴 작업명 안내
- 별도로 준비한 CLI/AI Battery와 알림 연결

## 설치

Git for Windows와 [Microsoft Visual C++ v14 x64 런타임](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)을 먼저 준비한 뒤 `MiniTerm-0.1.0-alpha.1-windows-x64-setup.exe`를 실행하세요. MiniTerm 설치는 관리자 권한이 필요하지 않으며 별도 런타임 설치에는 권한이 필요할 수 있습니다. 압축형 ZIP도 제공하며 같은 사용자 설정 경로를 사용합니다. 설치 파일은 서명되지 않았습니다. `SHA256SUMS`로 파일을 확인하세요.

## 알려진 문제

- 기본 Git Bash에서 리사이즈 직후 첫 글자가 누락될 수 있습니다. 격리 MSYS 수정본의 검사는 통과했지만 이번 배포에 포함하지 않습니다.
- 일부 앱 샘플은 200MB 메모리 목표를 초과했습니다. 출력 부하·GPU·입력→화면 지연 전체 기준은 아직 검증하지 않았습니다.
- 실제 한글 IME·단축키·Windows 알림 클릭, 다른 장치/DPI·깨끗한 설치/업데이트·실제 계정 응답의 전체 검증이 남아 있습니다.
- WSL2는 선택 프로필이며 개발 장치의 서비스 오류가 남아 있습니다.
- 진행률은 명시된 작업 항목을 기준으로 합니다. 모든 에이전트의 작업을 자동 분석하지 않습니다.

기본 Git의 해당 CI 재검사 결과는 첨부된 `COMPATIBILITY.json`을 확인하세요. 실제 전체 통과 여부와 알려진 실패의 알파 허용 여부를 구분합니다.

설치·업데이트·제거 전 진행 중인 셸 작업을 마치고 트레이에서 MiniTerm을 종료하세요. 열린 세션은 재설치 후 자동 복구되지 않습니다.
